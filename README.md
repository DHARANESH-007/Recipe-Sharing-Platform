Recipe sharing platform done in EY-GDS Internship.

Tech Stack: React.js, Bootstrap, Node.js, Express.js, MongoDB


• Built a full-stack web app to suggest recipes based on user-input ingredients using the Spoonacular API
• Developed a responsive React.js frontend with React Router and Bootstrap for clean navigation and UI
• Created RESTful APIs with Node.js and Express.js, and stored user data using MongoDB with Mongoose
